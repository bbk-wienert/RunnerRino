# RunnerRino
## Stundenergebnis
Wir haben uns als Gruppe überlegt, ein Ausweichspiel zu entwickeln, das an Spiele wie Subway Surfers oder Temple Run angelehnt ist.

Der Charakter bewegt sich dabei automatisch durch eine Strecke und muss verschiedenen Hindernissen ausweichen. Die Steuerung soll nicht über Tastatur oder Controller erfolgen, sondern über Körperbewegungen bzw. Posen.

##Geplant sind zunächst folgende Bewegungen:

- Links → Charakter bewegt sich nach links
- Rechts → Charakter bewegt sich nach rechts
- Ducken → Charakter duckt sich
- Springen → Charakter springt

Die Anwendung soll die Bewegungen des Spielers über eine Kamera erkennen und die erkannte Pose anschließend in eine entsprechende Aktion im Spiel umwandeln.

Unser Ziel ist es, im weiteren Verlauf zunächst die Posenerkennung umzusetzen und anschließend die Verbindung zwischen der erkannten Bewegung und der Spielfigur herzustellen.
